## What "digital identity" means here

A system whose primary product is *being someone* — proof of attributes, verifiable credentials, account-as-identity flows, sign-in services, reputation systems, or sovereignty-oriented identity. Not products where identity is incidental to the main flow.

For these products, the chain's account model and profile layer are doing more architectural work than for any other category — and the matrix above weights those rows accordingly.

## The Sybil red herring

Web2 platforms — Twitter, Instagram, Reddit, TikTok — all reached mass adoption with 5–20% estimated bot populations. Sybil resistance was never the blocker for user growth. It's a downstream problem that matters for airdrops, one-person-one-vote systems, and specific reputation flows — not for the median user shipping a consumer product.

Worldcoin's Orb-based iris-scan approach makes Sybil resistance cryptographically strong, but adds its own frictions: physical Orb access is geographically limited, users must show up in person to verify, and biometric collection creates a new trust problem. For a mass-adoption consumer identity system, Sybil resistance is not the load-bearing decision.

## What actually blocks blockchain UX

Every consumer team building on Ethereum today hits the same list:

1. Wallet install and seed-phrase onboarding
2. Gas acquisition before the first action
3. Unlimited token approvals with no revoke UX
4. A wallet popup for every action
5. No portable identity across apps — every product asks the user to configure a profile from scratch
6. Lose the key, lose everything

Fixing this list — not Sybil resistance — is what catalyzes mass adoption. The LUKSO account stack is architected around this diagnosis: smart account by default (LSP0), scoped revocable permissions (LSP6), standardized portable profile (LSP3), relayer-native gasless onboarding (LSP25), and multi-controller recovery. Account abstraction on Ethereum (ERC-4337, EIP-7702) addresses parts of this list at the infrastructure layer; LUKSO addresses all of it at the protocol layer.

## Where Worldcoin fits

World ID is a good tool for the problems it solves — proof-of-personhood for airdrops, quadratic voting, and attestation-gated actions. Nothing in this comparison rules out layering World ID on top of a LUKSO Universal Profile via a custom attestation contract or an LSP3 claim key. The point is that Worldcoin is a specialist tool for a specific problem, not a general identity platform for consumer apps. Compose the specialist tool where the flow requires it; don't pick the chain around it.
