LSP3 is small. It says: if every Universal Profile uses these data keys for the same things,
every app can read every profile without per-app conventions. The profile itself is a
contract (LSP0), the *information about the profile* lives in ERC-725Y data keys, and LSP3
names the canonical ones.

Pair with LSP5 (received assets) and LSP12 (issued assets) for the full identity-side picture
of what a profile holds and what it created.
